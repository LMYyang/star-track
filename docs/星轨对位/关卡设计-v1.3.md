# 星轨对位 · 关卡设计 v1.3（第 15–17 章）

本版在 v1.2（96 关 / 14 章）基础上新增 **36 关 / 3 章**，总量 **132 关 / 17 章**，并引入两种此前没有的对称机制：

- **星芒（八重对称，`d4`）**：旋转 + 镜像合成 8 阶群，一个源点补七颗。
- **星阵（平移复制，`t`）**：整片星图沿向量平移复制 1–3 步。

原有的平面镜、横轴、斜轴、中心对称、双轴（十字）、四重旋转、复合双镜（`g`）全部保留，第 17 章把它们和两种新机制混排。

## 2. 新元素「星芒」：八重对称 `d4`

记中心 $(c_x, c_y)$，用半格坐标 $h_x = 2c_x,\ h_y = 2c_y$（`hx+hy` 必须为偶数，否则转 90° 会落到半格）。

**四个旋转**（顺时针 90°，`s=(hx+hy)/2`、`d=(hy−hx)/2`）：

\[
R^0=I,\quad R=\begin{pmatrix}0&-1\\1&0\end{pmatrix}+\begin{pmatrix}s\\d\end{pmatrix},\quad R^2=(2c_x-x,\ 2c_y-y),\quad R^3=\begin{pmatrix}0&1\\-1&0\end{pmatrix}+\begin{pmatrix}-d\\s\end{pmatrix}
\]

**镜轴**必须过中心，可取 `v`（$x=c_x$）、`h`（$y=c_y$）、`d1`（$y=x+c,\ c=c_y-c_x$）、`d2`（$x+y=c,\ c=c_x+c_y$）。

**群** = 四条旋转 ∪ 四条「旋转 ∘ 镜像」，共 8 个元素（二面体群 $D_4$）：

\[
G=\{R^k\}\cup\{R^kM\},\quad k=0..3
\]

- 一个源点的像 = 7 颗，绕中心成两层「星芒」。
- 结果恒为整数格点（`hx+hy` 偶）。
- **死格**：过中心的镜轴整条（9 格），中心格也在轴上。
- 方向随群元素变换：转 90° 时 `R→D→L→U`，镜轴把方向翻回去。

第 97 关实测：7×7、中心 (3,3)、竖轴，一源补 7，提交 4 次、提示 1 次、难度 3/5。

## 3. 新元素「星阵」：有限平移 `t`

定义向量 $(v_x, v_y)$（整数、非零）与步数 $k$（1–3），群取前 $k$ 次平移：

\[
G=\{I,\ T,\ T^2,\ \dots,\ T^k\},\quad T(x,y)=(x+v_x,\ y+v_y)
\]

- 群阶 = `steps + 1`；一个源点的像 = `steps` 颗（沿同一直线等距排开）。
- **没有轴格**：任何格点都能落星，边界由「像越界即非法」兜住 —— 生成器因此只把源点放在朝向板内的位置。
- 方向不变（平移不翻转箭头），所以第 16 章不放箭头关。
- 视觉：棋盘上从首颗源星拉一条金色虚线箭头，长度正好是 `steps` 个向量，提示复制方向与次数。

第 114 关实测：9×9、向量 (1,2)、2 步，3 源点补 6，提交 4 次、提示 0 次、难度 3/5。
