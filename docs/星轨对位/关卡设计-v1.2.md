# 星轨对位 v1.2：新增元素与新章（设计说明）

> 对应数据：`src/data/levels.v3.json`（96 关）、`docs/星轨对位/关卡数据-v3.json`（存档副本）
> 生成脚本：`scripts/gen-levels-v3.mjs`（改关卡后先跑校验、再跑 `npm run gen:golden`）

## 一、新对称元素：复合双镜（`sym.type = "g"`）

### 数学定义

由两条**二阶镜轴** A、B 组合成的四阶群 `{I, A, B, A·B}`，要求两轴**可交换**（`A·B = B·A`），否则集合不封闭、不能当群用。

构造：

```
normalizeSym({ type: 'g', a: { type: 'd1', c: 0 }, b: { type: 'd2', c: 6 } })
```

- 子轴只允许 `v / h / p / d1 / d2`（各自二阶），嵌套 `g` 或 `r` 直接拒绝。
- 两轴重合、或 `A·B = I`（退化）也拒绝。
- `groupOf('g')` 返回 `[I, A, B, A·B]`，`groupOrder` 直接取群元素个数（不再维护对照表）。

### 现有可交换组合

| 组合 | 结果群 | 说明 |
| --- | --- | --- |
| `v + h` | `cross`（已有） | 竖轴 + 横轴 = 十字 |
| `d1 + d2` | **新** | ╱ 与 ╲ 两条斜轴交叉成 X，第三像是绕交点转 180° |
| `v + p`、`h + p`（`d1 + p` 等满足 `hy − hx = 2c`） | 等价于已有群 | 不重复出题 |

### 判定口径

- 一个源点补**三点**（`targetCount = 源点数 × 3`）。
- **两轴交点 = A·B 的不动点 = 死格**，与轴格一样不能落星（`axisCells('g') = 两子轴轴格 ∪ 交点`）。
- 目标必须落在整数格点：`hydrateLevel` 对目标坐标加了整数校验，防止奇偶错配的半格像。
- 复合镜下**方向会翻两次**：`d1 + d2` 时 `R → D → U → L`，所以第 13/14 章的箭头 + 双镜是全新组合。

## 二、新章与难度

| 章 | 名称 | 关数 | 区间 | 主机制 | 收紧项 |
| --- | --- | --- | --- | --- | --- |
| 11 | 双镜 | 8 | L65–72 | 复合双镜（斜轴 × 斜轴） | 源点 2→5，提交 5→3 |
| 12 | 深井 | 8 | L73–80 | 9×9 + 密集暗域（4–6 格） | 提交 4→3，提示 1→0 |
| 13 | 星锁 | 8 | L81–88 | 箭头 + 双镜/十字/旋转 + 暗域 | **提交 2–3 次**，提示 0–1 |
| 14 | 万象 | 8 | L89–96 | 双镜 + 暗域 + 残星 + 箭头 | **提交 2 次、零提示、盲判（不报偏差数）** |

### 难度系数 `difficultyOf(level)`（1–5）

口径：`1 + 目标数≥6 + 目标数≥9 + 暗域≥4 + 残星≥2 + 箭头 + 零提示 + 提交≤2`，封顶 5。

- 前 10 章多数为 2–4；第 11–14 章新关集中在 3–5，L96「万象归一」为 5。
- HUD 副标题显示「难度 N/5」，星图册角标新增「双」标记复合双镜关。

## 三、数据与测试

- 旧 64 关**原样保留**在前 64 位；`levels.v1/v2.json` 留档，不删除。
- 生成器用真实 `hydrateLevel` 逐关校验，随机源点/暗域/残星用确定性种子（可复跑）；容量不够时优先「少放一个源点」而不是产出不可解关。
- 测试更新：全量 96 关黄金快照、96 关通关演练（真实 `useStar` 状态机逐关三星）、零提示关「提示必须返回空」、复合双镜群运算/交换性拒绝/方向翻折各一条。
- 校验脚本 `npm run validate:levels` 输出 96 关体检表（新增 `dual(d1+d2)` 对称标签）。
